# LeetCode SQL Solutions

Repositório dedicado à resolução de problemas de SQL da plataforma LeetCode, com o objetivo de documentar e aprimorar o desenvolvimento de consultas e manipulação de bases de dados.

---

## Estrutura do Repositório

Os códigos encontram-se organizados por níveis de dificuldade:

- **01 - easy/** — Problemas básicos com foco em comandos fundamentais (`SELECT`, `WHERE`, `ORDER BY`, `JOIN` simples).
- **02 - medium/** — Problemas intermediários com agregações avançadas e subconsultas.
- **03 - hard/** — Problemas avançados com lógicas relacionais complexas.

- **Plataforma:** LeetCode
